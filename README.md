# Punto Com · sitio web

El sitio de Punto Com, mi ciber y gestoría de trámites en Mariano Acosta, Merlo. Está publicado en [ciberkioscopuntocom.com](https://ciberkioscopuntocom.com).

*Website for Punto Com, my own cyber café and paperwork help desk in Mariano Acosta, Buenos Aires. Single HTML page with WhatsApp contact, Google reviews, map and local SEO.*

## El objetivo

Mucha gente llega sin saber si lo que necesita se puede hacer acá: un turno de ANSES, la VTV, un trámite de Migraciones. El sitio lista cada trámite con una explicación corta, y para consultar alcanza con un toque a WhatsApp.

## Qué tiene

- Una sección por organismo: ANSES, ARCA/AFIP, PAMI, SUBE, Migraciones, Mi Argentina, VTV, VPA, DNRPA, Reincidencia, VERAZ, TAD y Registro Civil.
- Reseñas de clientes de Google.
- Mapa embebido con la ubicación del local.
- Datos estructurados (JSON-LD) para aparecer en búsquedas locales.
- Imágenes en webp para que cargue rápido desde el celular.

## Verlo en local

Abrí `index.html` en el navegador. No necesita build.
